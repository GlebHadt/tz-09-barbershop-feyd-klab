# Источники изображений

Все изображения сайта созданы нейросетью **Claude (Anthropic, модель Claude Opus 5.5)**: она написала скрипт на Python (библиотека Pillow), который нарисовал стилизованные иллюстрации в фирменных цветах. Фотографии реальных людей и чужие снимки не использовались.

| Файл | Что изображено | Формат, размер | Источник |
|---|---|---|---|
| img/hero.webp | Первый экран: силуэт клиента и ножницы | WebP 1600×900 | сгенерировано (Claude + Pillow) |
| img/work-01…work-24.webp | 24 стрижки: фейд, кроп, классика, борода | WebP 720×720 | сгенерировано (Claude + Pillow) |
| img/master-1…master-8.webp | Иллюстрации-портреты мастеров (персонажи вымышлены) | WebP 600×750 | сгенерировано (Claude + Pillow) |
| img/gift.webp | Подарочный сертификат | WebP 800×500 | сгенерировано (Claude + Pillow) |
| img/og-image.jpg | Превью ссылки для соцсетей | JPEG 1200×630 | сгенерировано (Claude + Pillow) |
| img/favicon.ico, favicon.png, apple-touch-icon.png | Значок сайта (ножницы) | ICO/PNG | сгенерировано (Claude + Pillow) |

Все файлы меньше 300 КБ, у каждого `<img>` заполнен `alt`.

> Если будете заменять иллюстрации фотографиями (например, из Kandinsky, Шедеврума или Unsplash/Pexels), сохраните те же имена файлов, формат WebP/JPEG до 300 КБ и добавьте сюда строку с источником и ссылкой.
